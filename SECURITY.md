# Security Policy

## Supported Versions

The latest version on the default branch is supported for security updates.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

1. Open the repository on GitHub.
2. Go to the **Security** tab.
3. Select **Report a vulnerability**.
4. Include reproduction steps, impact, and any proof-of-concept details.

Do not open public issues for unpatched vulnerabilities.

## Response Process

- We will acknowledge valid reports as quickly as possible.
- We will investigate, prioritize, and provide remediation guidance.
- We may request additional details to reproduce and validate the issue.
