# Security Policy

## Supported Versions

This project currently supports security updates for the latest version on the default branch.

## Reporting a Vulnerability

Please do not open public issues for security reports.

Do not submit malware, intentionally harmful code, or obfuscated payloads in reports or pull requests.

Instead, report vulnerabilities privately through GitHub Security Advisories:

1. Go to the repository "Security" tab.
2. Select "Advisories".
3. Create a new draft security advisory with reproduction details and impact.

Include:

- A clear description of the issue
- Reproduction steps
- Affected versions/commits
- Any suggested mitigation

## Response Process

We will acknowledge valid reports and work on remediation as quickly as possible.

For private disclosure, use the repository's GitHub security advisory workflow.
